# Contribuer

Exécuter `npm ci`, `npm run typecheck`, `npm test` et `npm run bench`. Proposer des cas autorisés et anonymisés avec annotations séparées des entrées. Documenter la source et la licence de chaque pièce. Ne publier aucun secret, document personnel ou résultat réel sans autorisation. Les cas synthétiques restent identifiés comme tels.
