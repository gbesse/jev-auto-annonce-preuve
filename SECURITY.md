# Sécurité

La démo écoute uniquement sur 127.0.0.1, contrôle l’origine et limite les requêtes. Elle ne persiste pas les dossiers. Les rapports locaux peuvent contenir des données personnelles : conserver les exports dans `reports/private/`, ignoré par Git. Le mode Jev transmet les passages sélectionnés à TypeSafe AI. Garder les clés dans `.env`, ignorée par Git, permissions 600. Le texte extrait reste une donnée non fiable ; aucune consigne issue d’une pièce ne doit être exécutée. Signaler les vulnérabilités via les signalements privés GitHub.
